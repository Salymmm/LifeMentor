# 第二轮 Android 改进记录

更新日期为 2026-11-26。

## 功能变化

### 导师与任务联动

- 导师可以按问题读取当前任务，支持今日到期、今日完成、逾期、未排期、指定目标和全部任务。查询记录包含标题、所属目标、父任务、层级、日期和完成状态。
- 聊天增加 Task scope 选择器和分页入口。全部任务可以覆盖已完成目标，逾期查询默认关注进行中的目标。
- 普通聊天沿用进度摘要。按需查询的记录作为数据传入模型，历史任务查询回复在后续上下文中以摘要标记替代。
- 导师的完整回复增加 Add to plan。点击后发起一次独立的模型请求，提取一条具体行动，用户编辑标题、选择进行中的目标、可选父任务和日期后确认保存。
- 清空聊天增加当前导师的二次确认，取消保留历史记录。

### 目标和 AI 拆解

- AI 拆解先展示三层任务树草稿，可以展开、收起、改标题、设日期和删除分支。
- 用户点击 Save tasks 后才写入任务。取消草稿保留原有计划，确认时重新校验目标状态并保留手动任务。
- 拆解保存使用原子文件替换和恢复标记，启动时可恢复中断的确认操作。
- 点击任务正文展开或收起，右侧横向 ⋯ 菜单提供任务管理。已保存任务支持从菜单添加子任务。
- 外层 Goal 增加完成复选框，支持取消完成，管理菜单统一为横向 ⋯。
- AI-decompose 使用黄色贴纸和蓝色阴影，操作区保持垂直居中。

### 首页和聊天界面

- 首页角色名片内增加 Show growth / Hide growth，直接展开或收起五维成长图，默认收起。
- 首页和 Goals 页的日历入口统一为日历图标。
- 双方消息支持复制，使用双层图标。导师消息的复制与 Add to plan 位于同一操作行。
- 统一导师正文和操作行的左边缘，缩短底部操作行与正文之间的距离。
- Task scope 与 Simulation 同行显示，窄屏可以横向滚动。
- 每位导师的回复气泡固定使用其主题色的浅色版本。

## 验证

提交前已重新执行以下命令。118 项 Android 单元测试和 21 项 Python 测试通过，应用调试包与 Android 测试包均构建成功。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
python -m unittest discover -s tools -p "test_*.py"
```

本轮功能阶段已有 37 项隔离模拟器检查通过，覆盖目标管理、任务日期、拆解确认和中断恢复。后续布局与颜色调整完成了构建和单元测试，手机上的最终视觉验收仍需执行。导师工作流测试使用受控模型响应，真实 API 的完整流程需在配置接口后验证。

Windows 项目路径包含中文时，可使用空闲盘符映射到仓库后构建。例如先执行 `subst Q: "仓库绝对路径"`，进入 `Q:\` 后运行 Gradle。使用前确认盘符空闲。

## 手机验收清单

- 向导师询问今日任务与逾期情况，在 App 修改任务后再次询问，核对最新状态。
- 查询全部任务并翻页，核对已完成目标和任务的范围。
- 生成拆解草稿，测试折叠、编辑日期、删除分支、取消和确认保存。
- 从导师建议生成待办，编辑后保存，核对目标树和 App 日历里的同一条记录。
- 测试清空聊天的取消和确认，核对另一位导师的聊天历史。
- 核对消息复制的内容、操作行对齐、每位导师的固定气泡颜色和窄屏按钮布局。
- 在角色名片内展开、收起五维成长图，核对两个页面的日历入口。

本轮交付为 Android。iOS 仍待后续开发。
