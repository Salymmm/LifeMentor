# Generic Subtasks Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for this change.

**Goal:** Replace calendar-named manual tiers with tasks and recursively nestable subtasks.

**Architecture:** Parent IDs determine nesting independently of the existing reward tiers. New manual nodes use the existing action tier (level 3), so tasks at every nesting depth already participate in the agenda/reminder system and earn the existing action reward. Existing task JSON, AI reward tiers, AI titles and AI generation/validation remain unchanged. Visible rows carry actual tree depth, and traversal uses an explicit stack rather than recursion.

**Tech Stack:** Existing Kotlin/Compose, JSON storage, JUnit; no new dependencies.

**Spec:** User requests on 2026-11-16: remove the milestone name, use task/subtask relationships, and allow every task to have further subtasks without a three-layer limit. Dates stay optional and independent of hierarchy. The user explicitly selected unlimited manual nesting. Prior authorization to implement continues; no AI modification is authorized.

## Global Constraints

- Do not modify B's prompts, schema, parser, evaluator, mentor logic or AI-generated titles.
- Preserve old IDs, relationships, completion state, dates and historical XP.
- Root creation is "添加任务"; child creation is "添加子任务" under any active-goal task.
- Use parent-derived depth, bound visual indentation, and wrap row actions so deep nesting stays readable.
- Goal completion does not automatically complete descendants; existing independent task completion behavior remains.

## Review Focus

- New child under any legacy AI tier must be accepted without changing that parent's data.
- Nested manual tasks at depths beyond three must remain date/reminder eligible.
- Root action-tier tasks must render at depth zero, while child action-tier tasks render at their actual depths.
- Expanded descendants of a collapsed parent must remain hidden.
- Completed goals and in-progress AI decomposition must keep their existing mutation guards.
